# Changelog

## 1.0.0 (2026-09-17)

- Initial release
- Six-signal scoring: name, description, topics, README, stars, activity
- Weighted overall score with letter grades (A-F)
- Target query keyword matching for name scoring
- Multi-repo audit in one command
- JSON output mode
- Actionable tips for low-scoring signals
- Rate-limit aware with automatic GitHub token support
